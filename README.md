# hedgehog

Game created with `shinyphaser` R package. Play it here:

<https://maciekbanas.shinyapps.io/hedgehog/>

## Run locally

From the repository root in R:

```r
install.packages(c("shinyphaser", "shiny", "shinyalert", "later", "purrr"))
shiny::runApp("hedgehog.R")
```

Use shinyphaser 0.2.0 or later.
